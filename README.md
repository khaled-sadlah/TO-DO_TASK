# Task Manager

A browser-based task manager built with vanilla JavaScript, HTML and CSS as a web development exercise.

## Features

- Add and edit tasks with input validation.
- Mark tasks complete and filter the task list.
- Delete individual tasks, completed tasks or all tasks with confirmation dialogs.
- Save tasks in the browser using localStorage.

## Run

Open `index.html` in a browser. No installation or build step is required.

## Files

- `index.html`: interface and dialogs.
- `script.js`: task management, validation and persistence.
- `style.css`: presentation.

Tasks are stored in the current browser, rather than in a shared server database.
